# 244107020128-mobile-course

Portfolio perkuliahan Pemrograman Mobile — 16 minggu.

Satu repository pribadi mendokumentasikan progres selama satu semester.
Setiap folder `NN-week-*` berisi README, kode (`lib/`), test (`test/`),
dan bukti visual (`screenshots/`).

## Struktur

- `01-week-1-mobile-development-ecosystem-flutter-refresh/` — ekosistem mobile & Flutter refresh
- `02-week-2-declarative-ui-responsive-design/` — declarative UI & responsive layout
- `03-week-3-navigation-state-management/` — routing & state management (Riverpod)
- `04-week-4-networking-rest-api/` — HTTP client Dio & integrasi REST API
- `05-week-5-local-storage-offline-first/` — SQLite storage & repository offline-first
- `06-week-6-authentication-security-fcm/` — secure storage & Firebase Cloud Messaging
- `07-week-7-clean-architecture/` — refactoring feature-first Clean Architecture
- `08-week-8-mid-project-review/` — mid-project review, code review, CI/CD, & evaluasi AI
- `09-week-9-ai-assisted-development/` — AI-assisted development, vibe coding, search filter, & AI code review
- `10-week-10-ai-feature-integration/` — integrasi fitur AI chat assistant, streaming token, privacy guard, & offline fallback
- `11-week-11-performance-optimization/` — optimasi performa, DevTools CPU/memory profiling, const widget, repaint boundary, & lazy loading
- `notes/` — reflections, learning-journal, resources
- `portfolio-summary.md` — ringkasan akhir semester

## Cara menjalankan (umum)

```bash
cd 01-week-1-mobile-development-ecosystem-flutter-refresh
flutter pub get
flutter run
```

> Catatan: build dilakukan di `C:\flutter_course\week1` (OneDrive memblokir MSBuild).
> Source disini untuk version control & pengumpulan.
